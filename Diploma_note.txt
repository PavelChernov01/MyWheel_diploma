                ПОЯСНИТЕЛЬНАЯ ЗАПИСКА
                К ДИПЛОМНОМУ ПРОЕКТУ

Тема: Разработка веб-сайта для публикации и поиска объявлений о продаже автомобилей с пробегом MyWheel
________________________________________
1. ВВЕДЕНИЕ
1.1 Актуальность темы
Рынок автомобилей с пробегом в России и Беларуси активно растёт. Ежегодно продаётся более 5 миллионов подержанных автомобилей, что значительно превышает объём продаж новых машин.
Большинство сделок совершается через интернет-платформы.Современные пользователи ожидают от таких платформ удобного поиска, достоверной информации о продавцах и автомобилях, а также безопасности сделок.
Существующие решения имеют недостатки: отсутствие прозрачной системы оценки продавцов, недостаточная гибкость поиска, неполная модерация объявлений.
Поэтому разработка современной и безопасной платформы для публикации и поиска объявлений о продаже автомобилей является актуальной задачей.

1.2 Цель проекта
Разработка веб-платформы для публикации и поиска объявлений о продаже автомобилей с пробегом, обеспечивающей полный цикл работы с объявлениями и безопасное взаимодействие между участниками рынка.

1.3 Задачи проекта
1.	Провести анализ предметной области
2.	Спроектировать структуру базы данных
3.	Разработать систему регистрации и аутентификации пользователей
4.	Реализовать полный цикл работы с объявлениями
5.	Создать систему поиска и фильтрации
6.	Реализовать дополнительные функции (избранное, отзывы, рейтинг)
7.	Разработать интерфейс для администратора
8.	Обеспечить документирование API

2. ОПИСАНИЕ ПРОЕКТА

2.1 Основные функции сайта

Сайт предназначен для трёх групп пользователей:
Продавцы — люди, которые хотят продать свой автомобиль. Они могут создавать объявления с фотографиями, указывать характеристики автомобиля и редактировать свои объявления.
Покупатели — люди, которые ищут автомобиль. Они могут искать машины по разным параметрам, сохранять понравившиеся объявления и оставлять отзывы о продавцах.
Администраторы — люди, которые следят за порядком на сайте. Они проверяют новые объявления, управляют пользователями и следят за соблюдением правил.
2.2 Основные возможности

Регистрация и вход. Пользователи могут зарегистрироваться на сайте, указав email, имя и пароль. После регистрации доступен личный кабинет. При забытом пароле можно восстановить его через email.
Объявления. Продавец создаёт объявление с указанием марки, модели, года, цены, пробега и других характеристик. Можно загрузить несколько фотографий. Объявление проходит проверку администратором перед публикацией.
Поиск. Покупатель может искать автомобили по цене, году, марке, модели и городу. Результаты можно сортировать. Есть поиск по описанию.
Избранное. Понравившиеся объявления можно сохранять в избранное. Все сохранённые объявления собираются в отдельном разделе.
Отзывы. Покупатель может оставить отзыв о продавце после покупки. У каждого продавца формируется рейтинг на основе полученных отзывов.
Модерация. Все новые объявления проверяет администратор. Это помогает защитить покупателей от мошенников.

3. ИСПОЛЬЗУЕМЫЕ ТЕХНОЛОГИИ

3.1 Язык программирования и фреймворки

Python — язык программирования, на котором написан весь сайт. Отличается простотой и широким применением в веб-разработке.
Django — фреймворк для создания сайтов на Python. Предоставляет готовые решения для работы с пользователями, базами данных и админ-панелью.
Django REST Framework — расширение Django для создания API. Позволяет сайту взаимодействовать с мобильными приложениями.

3.2 Базы данных

SQLite — база данных, использованная на этапе разработки. Не требует установки, хранит все данные в одном файле.
PostgreSQL — более мощная база данных, настроенная через Docker. Используется в реальных проектах.

3.3 Дополнительные инструменты

Redis — используется для кеширования данных, что ускоряет загрузку страниц.
Docker — позволяет запускать сайт в изолированных контейнерах. Используется для запуска PostgreSQL и Redis.
JWT — способ аутентификации, при котором пользователь получает токен для входа.
Swagger — инструмент для автоматической документации API.
Bootstrap — готовый набор стилей для оформления страниц.

4. АРХИТЕКТУРА ПРОЕКТА

4.1 Структура проекта

Проект разделён на модули, каждый из которых отвечает за свою задачу:
Модуль	Назначение
accounts	Регистрация, вход, профиль пользователя
brands	Справочники марок, моделей, характеристик
cars	Создание, просмотр, поиск объявлений
favorites	Избранное
reviews	Отзывы и рейтинг продавцов
roles	Права доступа пользователей
moderation	Проверка объявлений администратором
pages	Страницы «О нас», «Контакты», «Помощь»

4.2 Схема базы данных

В базе данных хранятся все сведения о пользователях, объявлениях и автомобилях:
Таблица	Содержание
Пользователи	email, телефон, имя, аватар, рейтинг
Марки	Названия производителей
Модели	Названия моделей с привязкой к марке
Объявления	Марка, модель, год, цена, пробег, описание
Фотографии	Ссылки на загруженные изображения
Избранное	Связь пользователя с объявлением
Отзывы	Оценка и комментарий о продавце

4.3 Пагинация

На главной странице отображается не более 9 объявлений. При большем количестве внизу появляются номера страниц. Это ускоряет загрузку и упрощает навигацию.

4.4 Кеширование

Некоторые данные редко меняются, но часто запрашиваются. Например, статистика на главной странице. Такие данные сохраняются в Redis и отдаются быстрее, что ускоряет работу сайта.

4.5 Модерация

При создании объявления оно получает статус «На модерации» и не показывается на сайте. Администратор проверяет объявление и решает: опубликовать или отклонить.

5. РЕАЛИЗАЦИЯ ПРОЕКТА

5.1 Регистрация и аутентификация

Пользователь заполняет форму с email, именем и паролем. Данные сохраняются в базу. При входе система проверяет email и пароль, выдаёт JWT-токен для доступа.
При забытом пароле отправляется письмо с ссылкой для сброса.

5.2 Создание объявления
Продавец заполняет форму с характеристиками автомобиля, загружает фотографии. После отправки объявление попадает на модерацию. Редактировать и удалять объявление может только его владелец.

5.3 Поиск и фильтрация

Покупатель может использовать фильтры по цене, году, марке, модели, городу. Доступен текстовый поиск по описанию. Результаты можно сортировать.

5.4 Избранное

Кнопка «В избранное» добавляет объявление в список сохранённых. Это помогает не потерять интересные варианты.

5.5 Отзывы

Покупатель оставляет оценку и комментарий. На основе отзывов формируется средний рейтинг продавца.
